We used the prepared Statistics Canada Food insecurity by selected demographic characteristics CSV and restricted the cohort to British Columbia only. We reported missingness for the key variables before selecting complete records for GEO (geographic information), Demographic characteristics, Household food security status, REF_DATE (year), VALUE (number of people). The grouped summary reports estimated number of persons by Household food security status; the figure shows estimated number of persons by household food security status. These results describe the prepared household food security records and cannot support causal claims.
